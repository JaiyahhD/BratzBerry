# BRATZBERRY™ — Bunny Boo Edition
A mobile-friendly interactive phone gift from Yasmin to Sasha.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Customize
- Edit `letters` in `script.js` to replace all sample Open When messages with your real letters.
- Change colors and phone appearance in `style.css`.
- Replace the placeholder Memories, Music, and Notes app content in `script.js`.

## Deploy
Create a GitHub repository, push these files, and connect the repository to Netlify. No build command needed; publish directory is the project root (`.`).

Note: Read/unread state is saved only on the browser/device used. The site is public to anyone who has its URL unless you add access controls.
